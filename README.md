# 📝 AuthentiText — AI-Generated Essay Detector

An end-to-end NLP project that classifies essays as **human-written** or **AI-generated** using classical machine learning and TF-IDF text features, with an interactive Streamlit web app for real-time predictions.

---

## 📌 Project Overview

With the rise of large language models (LLMs) like ChatGPT, distinguishing human-authored writing from AI-generated text has become an important problem for education, publishing, and content moderation. **AuthentiText** builds a full pipeline — from raw text to a deployable web app — that tackles this as a binary text classification task.

**Best model achieved (on held-out test set): ~99.8% accuracy, ~0.997 F1-score, ~1.00 ROC-AUC** (Linear SVM). See the notebook and project report for full results.

## 📊 Dataset

- **File:** `Training_Essay_Data.csv`
- **Dataset Source:** [Kaggle](kaggle.com/datasets/sunilthite/llm-detect-ai-generated-text-dataset)
- **Rows:** 29,145 essays
- **Columns:**
  - `text` — the essay content
  - `generated` — label: `0` = human-written, `1` = AI-generated
- **Class balance:** ~60% human, ~40% AI-generated

---

## ⚙️ How It Works

1. **Text Cleaning** — lowercasing, URL/number/punctuation removal, whitespace normalization
2. **Feature Extraction** — TF-IDF vectorization (unigrams + bigrams, top 15,000 features)
3. **Modeling** — four classifiers trained and compared:
   - Logistic Regression
   - Multinomial Naive Bayes
   - Linear SVM (calibrated for probabilities)
   - Random Forest
4. **Model Selection** — best model chosen by F1-score on a held-out test set, validated via 5-fold cross-validation
5. **Deployment** — the trained model and vectorizer are saved with `joblib` and loaded by a Streamlit app for interactive and batch predictions

## 🚀 Getting Started

### 1. Clone / download the project and install dependencies

```bash
pip install -r requirements.txt
```

### 2. Train the model (run the notebook)

Open and run all cells in:

```
AuthentiText_AI_Essay_Detection.ipynb
```

This will:
- Perform EDA and generate visualizations in `outputs/`
- Train and evaluate all four models
- Save the best model as `outputs/best_model.pkl` and the vectorizer as `outputs/tfidf_vectorizer.pkl`

> ⚠️ The Streamlit app requires these two files to exist — run the notebook first.

### 3. Launch the Streamlit app

```bash
streamlit run app.py
```

Then open the local URL shown in your terminal (typically `http://localhost:8501`).

## 🖥️ Using the App

The app has three tabs:

| Tab | Description |
|---|---|
| **🔍 Single Essay Check** | Paste or type an essay (or try a built-in sample) and get an instant Human vs. AI-Generated prediction with a confidence breakdown and basic text statistics |
| **📂 Batch Check (CSV)** | Upload a CSV with a `text` column to classify many essays at once and download the results |
| **📊 Insights & Model Performance** | Displays all EDA and evaluation plots generated by the notebook (class distribution, word count/stylometric distributions, word clouds, model comparison, confusion matrix & ROC curves, top predictive terms) — loaded directly from `outputs/*.png` |
| **ℹ️ About the Project** | Explains the dataset, pipeline, and limitations |

## ⚠️ Limitations & Disclaimer

- Trained on a specific snapshot of human and AI-generated essays; performance may degrade on text from newer/unseen LLMs or non-essay genres.
- Uses lexical (TF-IDF) features only — no deep semantic/discourse modeling.
- This is an **educational project**. Predictions should **not** be used as sole evidence for academic integrity or disciplinary decisions.
